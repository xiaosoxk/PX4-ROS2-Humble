# 硬件架构与原理图说明

## 1. 双电源域（拓扑原则：动力与逻辑彻底分开）

```
6S 电池 ─ BMS(bq40z80: SOC积分/分级告警) ─┬─ 动力母线 ── 4in1 FOC 电调 ── 电机×4
   │                                      └─ 浪涌保护(TVS+理想二极管)
   ├─ 9V/3A 降压 ── 图传模组
   └─ 5V/10A 降压 ─┬─ Orin NX 载板(峰值 25W→10A 裕量必留)
                   └─ 飞控 5V→3.3V LDO(H743/传感器/RTK)
```
- 电机堵转瞬间母线跌落 ≥1.5V：Orin 供电必须独立降压 + 大电容(470µF×2)，
  否则电机急停会触发载板欠压复位（这是最多人踩的坑）；
- BMS 分级告警：75% 提示 / 40% 建议返航 / 25% 强制返航 / 15% 着陆
  （飞控侧 BAT_* 参数与 BMS SOC 取小者，防 BMS 单点失效）。

## 2. 通信拓扑

| 链路 | 物理层 | 协议 | 说明 |
|---|---|---|---|
| H743 ↔ Orin | UART TELEM2 921600（备份: ETH） | MAVLink v2 | ai_gateway 管辖, 见任务分区文档 |
| H743 ↔ 电调 | DShot600 | 数字协议 | 带电流/转速/温度回传(ESC 遥测) |
| Orin ↔ 相机 | MIPI CSI-2 ×6 | — | 主摄+前视双目；五向其余经 USB3 hub |
| Orin ↔ 激光雷达 | 100M ETH | Velodyne/Livox 私有 | Mid-360 |
| Orin ↔ 云台 MCU | UART 115200 | 自定义帧(AA55+crc8) | gimbal_ctrl.py |
| Orin ↔ 图传 | M.2 E-key / USB | 802.11ac OFDM | 视频复用遥测 |
| H743 ↔ RTK | UART1 | u-blox 二进制 | RTCM 由地面基站经图传链路注入 |
| 遥控 | 915MHz ELRS + 2.4G SBUS | CRSF/SBUS | 双频冗余, RC_LOSS 判据取两路 |

## 3. 飞控板布局要点（自研 4 层）
- 双 ICM42688 **对称布置于纵轴两侧等距位置**，同相位减振（共振对消）；
- IST8310 远离电机电流回路 ≥25mm，PCB 内层铺地隔离；
- MS5611 加开孔硅胶罩（防气流/光照）；
- H743 晶振、VDDA 磁珠隔离；SD 卡走线避开 IMU 区；
- DShot 信号线与 IMU 模拟区隔离，电调功率地单点汇入。

## 4. 接插件与维护性
- 所有机载节点经 XT30/PH2.0 标准接头；UART 经 GH1.25 锁扣；
- Orin 载板与机身用快拆托盘（检修/换算力板不用拆机）；
- 每条线缆两端标签（网络标号规则：`SRC-DST-信号`，例 `FC-ORIN-TELEM2_TX`）。

# 调试流程与可视化

## 1. 总原则：SITL → 台架 → 系绳 → 开阔地
任何 AI 功能按四级推进，每级全绿才进下一级（见制作指南 §6）。

## 2. PlotJuggler（姿态/角速度/PID/延迟）
1. PC 端：`ros2 run plotjuggler plotjuggler`；数据源选 ROS2 Topic，
   勾选 `/mavros/imu/data`、`/mavros/setpoint_raw/target_*`、`/ai/health`；
2. 布局文件存 `tools/plotjuggler_layout.xml`（角速率环四联图模板）；
3. 判读：PID 好坏的唯一标准是 **setpoint 与 actual 曲线的重合度与超调**，
   不要看绝对值。

## 3. Vofa+（串口快速波形）
飞控侧用 PX4 `sdlog` 或自写 debug 输出时，Vofa+ justfloat 协议最快上手：
调 `ai_gateway` 时把裁决中间量(倾角估计/围栏距离)以 50Hz 打包输出即可。

## 4. 延迟基准（AI 链）
```
ros2 run tools latency_bench     # 各节点 p50/p95 + 端到端合计, 预算 120ms
```
单项超标时的排查顺序：detector 输入节流→INT8 引擎是否真加载→GPU 频率锁
MAXN→ROS2 QoS(SensorData/BestEffort)→图像分辨率是否超 720p。

## 5. 飞行日志
- PX4 ulog：`pyulog` 提取, 论文图表从这里出；
- Orin：`ros2 bag record /ai/... /mavros/...`（SD 卡 1TB, 长时间录制用 zstd）；
- 地面站导出回放：轨迹 CSV + 视频 OSD 时间戳对齐（gcs_bridge 打点）。

## 6. RTK 基站架设
F9P 基站固定三脚架 → 测量天线坐标（已知点或平均 24h）→ RTCM 经图传上行
注入飞控 GPS1 口 → 飞控 EKF3 进入 RTK Fixed 后方可作为厘米级依据。

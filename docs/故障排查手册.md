# 故障排查手册（症状 → 根因 → 解法）

| # | 现象 | 最可能原因 | 定位手段 / 解法 |
|---|---|---|---|
| F01 | SITL 起不来 | PX4 版本≠1.14 / gz 冲突 | `make px4_sitl gz_x500` 手动跑看报错 |
| F02 | MAVROS 连不上 SITL | fcu_url 端口错 | SITL 默认 udp://:14540@ |
| F03 | offboard 切不进去 | setpoint 流未先发 | 必须先 ≥2Hz setpoint 再切模式 |
| F04 | AI 频繁熔断 | 心跳没发/延迟超阈 | `/ai/arbiter_status` 看 detail; latency_bench |
| F05 | 检测帧率只有 5fps | 没用 INT8 引擎/GPU 未锁频 | 看 detector 日志 TRT 加载行; nvpmodel MAXN |
| F06 | INT8 掉点 >5% | 校准集分布偏移 | 重选 500 张覆盖全部类别光照 |
| F07 | 双目深度全黑 | 曝光/基线标定错 | opencv stereo_calib 重标; 全局快门确认 |
| F08 | EKF 频繁重置 | 双 IMU 振动超限 | ulog 看 IMU 振动指标; 减振棉重贴 |
| F09 | UART 链路断续 | 波特率/地线/干扰 | 示波器看 TX; 换 ETH 备份链路 |
| F10 | 云台抖动 | 陷波频率没对准机身振动 | 实测振动频谱(PlotJuggler), 调 gimbal_ctrl notch |
| F11 | 跟随时云台滞后 | TRACK 增益低/链路延迟 | kp_track↑; latency_bench 里找云台链 |
| F12 | 电机异响+电流偏大 | 螺旋桨损伤/堵转前兆 | health_diag 告警即降落检查桨 |
| F13 | RTK 一直 float | 基站坐标未固定/天线遮挡 | 基站 24h 平均; 天线视野≥30° |
| F14 | 图传花屏 | 干扰/码率超链路 | 降码率 20Mbps→8Mbps; 自适应跳频日志 |
| F15 | 落地后 Orin 重启日志消失 | 欠压复位 | §1 供电电容; 单独降压供 Orin |
| F16 | 碰撞预防不生效 | CP_DIST=0 或 OBSTACLE_DISTANCE 没发 | 看 `/mavros/obstacle/send` 频率; obstacle_send 日志 |
| F17 | VINS 漂移越来越大 | 曝光弱光/纹理缺失 | vins_bridge drift 告警即回气压+光流; 补照明或纹理 |
| F18 | Web 地面站打不开视频 | 端口被占/防火墙 | server.py --video 与防火墙放行 14556/8000 |

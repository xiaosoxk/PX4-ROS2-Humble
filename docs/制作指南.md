# 航拍无人机制作指南（从零到首飞）

> ⚠️ **安全声明**：多旋翼航拍机不是玩具，螺旋桨是高速刀片。所有动力上电测试必须在**卸桨**状态；带桨测试必须系绳+护目镜+空旷无人区；遵守当地无人机管制法规（实名登记、限高、禁飞区）。本项目代码仅用于教学研究。

## 0. 准备
- 采购清单：`docs/BOM清单.md`（全配 ¥16k / 精简 ¥8k）；
- 工具：十字/内六角螺丝组、万用表、烙铁（自研飞控需焊接）、3D 打印机（云台件）、系绳（首飞）；
- 软件环境：PC 装 Ubuntu 22.04（或 WSL2）+ ROS2 Humble + PX4 SITL；Orin 刷 JetPack 5.x（含 TensorRT/CUDA）。

## 1. 仿真先行（0 硬件跑通全链路，1~2 天）
```
./scripts/sim.sh
```
验证顺序：MAVROS 连接 → offboard 切换 → follow_me 虚拟目标 → 熔断器
`Ctrl` 杀掉 detector 进程观察 0.5s 内回 POSCTL。**仿真全绿之前不买电机。**

## 2. 硬件组装（3~4 天）
1. 机架/电机/电调安装，卸桨状态跑电调遥测自检；
2. 飞控焊接（自研板）或 Pixhawk 接线：TELEM2→Orin、GPS1→F9P、SBUS 双接收机；
3. 双 IMU 贴减振棉，MS5611 加罩；
4. Orin 装托盘，NVMe、天线、CSI 相机排线（防静电）；
5. 云台：3D 打印件 + MT6701 磁环上轴（气隙 0.5mm），G431 最小系统板；
6. 电源：先只接 BMS+降压，**空载调压**后再接 Orin（同平衡车，见防反接/浪涌）。

## 3. 固件与配置（1 天）
```
make px4_fmu-v5_default EXTERNAL_MODULES_LOCATION=$PWD/firmware/px4_modules/ai_gateway
```
按 `docs/PX4配置与PID整定.md` 配 EKF3 冗余/failsafe/围栏；传感器校准
（加速度计 6 面板、双 IMU 各一次、磁力计远离电机）。

## 4. AI 部署（1 天）
Jetson 刷机 → 装 ROS2 Humble + MAVROS + TensorRT → `scripts/deploy_orin.sh`；
模型先跑 FP16 验证管线，再切 INT8。

## 5. systemd 开机自启（可选）
```
[Unit] Description=uav-ai
[Service] User=orin; ExecStart=/bin/bash -c 'source /opt/ros/humble/setup.bash; source ~/ros2_ws/install/setup.bash; ros2 launch bringup drone_bringup.launch.py'; Restart=always
[Install] WantedBy=graphical.target
```

## 6. 首飞检查单（逐项打勾）
- [ ] 卸桨：MAVROS 连接/遥测/ESC 遥测全通
- [ ] 卸桨：offboard 切换 + AI 指令清洗数值合理（mavlink_loopback）
- [ ] 卸桨：杀 AI 进程 → arbiter 熔断 → 飞控 0.5s 切 POSCTL（关键测试！）
- [ ] 装桨系绳：SITL 同参数下低油门自稳, EKF 无重置
- [ ] 系绳：位置模式小幅飞行, PlotJuggler 角速率环重合
- [ ] 空旷： attitude 定点悬停 5 分钟, 电池压降正常
- [ ] 开 OFFBOARD：定点由 Orin 维持（此时 AI=全零指令+心跳, 即最保守 AI 态）
- [ ] 逐个挂 critical_nodes：先 detector → 再 tracker → 最后 semantic_nav
- [ ] 每级都测"杀进程熔断"，全部通过后才有资格谈跟随/大师镜头

# 数据集说明

## 1. 类别（4 类，对应 ai_msgs/Detection.cls）
| id | 类别 | 主要来源 |
|----|------|---------|
| 0 | 行人（含骑行者） | 飞行采集 60% + VisDrone 公开集 |
| 1 | 车辆（轿车/公交/卡车/摩托） | VisDrone + 飞行采集 |
| 2 | 船只 | 公开水面数据集 + 飞行采集 |
| 3 | 动物（大型四足） | 公开集（较少，用强增广补） |

## 2. 采集计划（飞行采集部分）
- 高度 15/25/40m 三档 × 光照（晨/午/黄昏）× 视角（俯视 30°/垂直）
- 每档 ≥ 800 帧，总目标 ≥ 6000 帧；4K 录制后抽帧标注
- 采集时同时存原始图 + RTK 位姿（后续 3D 重建/回归测试用）

## 3. 标注与划分
- 工具：Roboflow / LabelImg，YOLO 格式；训练/验证/测试 = 8:1:1
- 注意跨"飞行架次"划分（同一架次的帧不跨集），防止泄漏虚高 mAP

## 4. INT8 校准集
- 500 张无标注图，覆盖全部类别与光照；分布须与训练集同源
- 校准图决定 INT8 量化范围——分布偏移会掉点 >5%

## 5. drone.yaml
```yaml
path: dataset/images
train: train.txt
val: val.txt
names: [person, vehicle, boat, animal]
```
## 6. 验收指标
- mAP50 ≥ 0.85（行人/车辆主类）；行人召回 ≥ 0.9（跟随安全底线）
- INT8 相对 FP16 掉点 ≤ 2 mAP
